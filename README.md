# Ryan Nemethy — AI Portfolio

A one-page site showing my AI projects and how my skills grew from using AI to building with it.

- `index.html`: the page layout and design
- `projects.js`: all content (projects, stages, toolkit). Edit this file to add or update a project.
- `shots/`: app screenshots. List them on a project with `shots:[...]` and its card gets a "See it" flip side.

Stats, stage dates, the "months building" count and the chart's time scale are calculated from today's date, so they stay current without edits.

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
